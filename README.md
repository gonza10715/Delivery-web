# Delivery Rápido — demo de pedidos

Proyecto de portfolio de **Gonzalo Martínez** hecho con HTML, CSS y JavaScript.

## Funcionalidades actuales
- Listado de restaurantes ficticios y menú.
- Buscador de restaurantes.
- Carrito de compras.
- Interfaz de opciones de pago **simuladas**.

## Ejecutar
Abrí `index.html` en un navegador. Los archivos `style.css` y `script.js` deben permanecer en la misma carpeta.

## Importante
**No es una tienda real. No procesa pagos ni confirma pedidos comerciales. No ingreses datos reales de tarjetas en los formularios de demostración.** Antes de publicar este proyecto como producto para clientes, hay que reemplazar las entradas de tarjeta por una simulación sin datos sensibles y completar las pruebas de accesibilidad y dispositivos móviles.

## Tecnologías
HTML5, CSS3 y JavaScript.
