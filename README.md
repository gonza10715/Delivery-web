# Delivery Rápido — demo de pedidos

Proyecto de portfolio de **Gonzalo Martínez** hecho con HTML, CSS y JavaScript.

## Funcionalidades actuales
- Listado de restaurantes ficticios y menú.
- Buscador de restaurantes.
- Carrito de compras.
- Interfaz de opciones de pago **simuladas**.

## Ejecutar
Abrí `index.html` en un navegador. Los archivos `style.css` y `script.js` deben permanecer en la misma carpeta.

## Importante
**No es una tienda real. No procesa pagos ni confirma pedidos comerciales.** La pantalla de tarjeta es una simulación sin campos para introducir datos bancarios. Antes de utilizar este proyecto para un negocio real, faltan un carrito con cantidades y total calculado, una única experiencia de confirmación, persistencia y pruebas de accesibilidad y dispositivos móviles.

## Tecnologías
HTML5, CSS3 y JavaScript.
